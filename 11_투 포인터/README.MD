\### 투포인터



이름과 같이 두 개의 포인터를 이용해 배열을 빠르게 탐색하는 알고리즘이다. 주로 배열의 양쪽 끝이나 한쪽 끝에 두 개의 포인터를 두고 조건에 따라 포인터를 움직이며 문제를 해결한다. 주로 입력 범위가 클 때 사용되며, 효율적인 코드 설계를 위해 사용된다. 



\### 문제 풀이



\####20922



&#x20;우선, N, M을 입력받고, 입력받은 N에 따라 vector에 수열을 입력받는다. 이후, left, right 두 개의 포인트를 이용해 문제를 해결한다. 우선 left와 right는 모두 0에서 시작하여 n까지 증가한다. for문을 통하여 right를 증가시키는데, 이 때, right 포인터가 가리키는 값을 cnt 수열에 1 증가시켜 해당 원소가 나온 횟수를 기록한다. 이 때, 만약 현재 cnt\[numbers\[right]] 값이 k보다 클 경우, left값(즉, 현재 계산 중인 수열의 첫 번째 위치)를 증가시킬 것임으로 cnt\[numbers\[left]] 값을 1 감소시키고 left를 1 증가시킨다. 이를 cnt\[numbers\[right]] > k가 아닐 때까지 반복하여 같은 원소가 k개를 초과하여 나오지 않는 배열의 시작점을 새로 잡는다. 

&#x20;이후, 기존 ans와 비교하여 현재 계산중인 수열의 길이(right - left + 1)가 길 경우 ans를 교체한다.
